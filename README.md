Piuscyber P4.0 PRO MAX is an OSINT-powered IP intelligence tool that scans any IP for geolocation, ISP, open ports, banners, and exposed camera detection with Shodan/Google Dork integration.

### ✨ Features (P4.0 PRO MAX)

- [x] **IP Geolocation:** City, Coordinates, Timezone
- [x] **ISP / Org Detection:** ASN & Organization lookup
- [x] **Port Scanner:** Detects open ports (Filtered detection)
- [x] **Banner Grabbing:** Service fingerprinting
- [x] **Camera Detection:** Checks for exposed network cameras
- [x] **Shodan + Google Dork:** Auto-generates intelligence links
- [x] **PRO MAX UI:** Hacker-style terminal dashboard
